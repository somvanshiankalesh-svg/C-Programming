
# 💻 C Programming Practice

## 📌 Project Overview
This repository contains my C programming practice programs and learning journey. It includes basic programming concepts, control statements, loops, arrays, functions, and other fundamental topics. The main goal is to strengthen my programming fundamentals and improve logical thinking and problem-solving skills.

- Improve logical thinking and problem-solving skills.
- Practice different programming problems.
- Build a strong foundation in programming.

## 💻 How to Run the Programs

1. Clone the repository:

   git clone https://github.com/somvanshiankalesh-svg/C-Programming.git

2. Open the project in your preferred IDE.

3. Select the C program you want to execute.

4. Compile the program:

   gcc filename.c -o output

5. Run the program:

   output.exe
